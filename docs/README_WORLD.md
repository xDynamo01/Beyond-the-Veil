# Beyond the Veil — World Documentation

This folder contains the official lore and worldbuilding documentation for **Beyond the Veil**.

## Core Topics
- The Veil (dimension rules, ruptures, energy, beasts)
- The City (districts, landmarks, political structure)
- Factions and their symbols
- Species (Velados, Umbrins, Sintonizados)
- Characters and story structure
- Concept Art Prompts (visual reference generation)

## Rule
Everything written here must respect the internal logic of the Veil:
- Power always has a cost.
- Exposure creates detection.
- Rituals are dangerous and scale by blood/essence.
- Umbrins are anomalies (Veil antibody), not Veil natives.
